Sales Custom Order Date

Add a custom date field to your sales orders and quotes

Overview

This module extends the Sales Order and Quote forms by adding a custom date field that allows users to manually select and track important dates related to their orders.

Features

  • Custom Order Date Field: Add a manually selectable date to any sales order or quote
  • Easy Access: Field is conveniently located in the order header for quick access
  • Change Tracking: All changes to the custom date are logged in the order chatter
  • List View Support: Optional column in list views for easy filtering and sorting

Use Cases

Perfect for tracking custom delivery dates, project milestones, customer-requested dates, or any other date-related information specific to your sales process.
