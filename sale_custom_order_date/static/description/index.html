Sale Custom Order Date

This module adds a custom order date field to sales orders and quotations.

Features

  • Adds a 'Custom Order' date field to sale orders
  • Field is manually selectable by users
  • Visible on quotation and order forms
  • Changes are tracked in the chatter

Usage

After installation, the 'Custom Order' field will appear on the sales order form, positioned near other date fields in the header section. Users can manually select any date as needed.

Configuration

No configuration is required. The field is available immediately after module installation.
