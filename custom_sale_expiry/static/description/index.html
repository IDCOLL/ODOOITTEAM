Sales Order Personal Expiry Date

Track personal expiry dates on your Sales Orders

Overview

This module adds a dedicated date field to Sales Orders for tracking personal or internal expiry dates. Perfect for managing time-sensitive orders, promotional periods, or custom expiration tracking.

Features

  • Add personal expiry dates to Sales Orders
  • Easy date picker interface
  • Changes tracked in order history
  • Visible in main Sales Order form
  • Does not copy when duplicating orders

How to Use

After installing the module, navigate to any Sales Order and you will see the new 'Personal Expiry Date' field. Simply click on the field to select a date using the date picker. The date will be saved with the order and any changes will be logged in the order's history.
