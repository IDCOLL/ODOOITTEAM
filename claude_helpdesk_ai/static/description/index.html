🤖 Claude AI Helpdesk Automation

Intelligent ticket analysis and automated code fixes

Overview

Transform your helpdesk operations with AI-powered ticket analysis. This module integrates Anthropic's Claude AI with Odoo Helpdesk to automatically analyze support tickets, propose code solutions, and create GitHub pull requests with fixes.

Key Features

🧠 Intelligent Analysis

Claude Sonnet 4.5 analyzes tickets to identify root causes and propose solutions based on your codebase.

⚡ Auto-Detection

Automatically detects affected Odoo modules from ticket descriptions and error logs.

🔗 GitHub Integration

Creates branches and pull requests directly from ticket analysis with complete code changes.

💰 Cost Optimization

Leverages prompt caching to reduce API costs by up to 90% for repeated context.

👥 Multi-Client Support

Configure different GitHub repositories and environments for each client.

📊 Analytics & Tracking

Track analysis history, PR creation, and success rates per client.

Requirements

Odoo 14+ Python 3.7+ Helpdesk Module

External Dependencies

  • Python Packages: anthropic, requests
  • Claude API: Anthropic API key with Claude Sonnet 4.5 access
  • GitHub: Personal Access Token with repo permissions

Installation

  1. Install Python dependencies:
    pip install anthropic requests
  2. Copy this module to your Odoo addons directory
  3. Update the apps list in Odoo
  4. Install "Claude AI Helpdesk Automation"
  5. Configure Claude API key in Settings → Technical → System Parameters:
    Key: claude_helpdesk_ai.api_key

Configuration

Per-Client Setup

  1. Go to Helpdesk → Configuration → Claude AI Configuration
  2. Select a customer/partner
  3. Open the "Claude AI & GitHub" tab
  4. Configure:
    • GitHub repository URL
    • GitHub Personal Access Token
    • Default branch and addons path
    • Odoo version and custom modules
    • Auto-analysis preferences
  5. Test the connection using "Test Connection" button

Usage

Manual Analysis

  1. Open a helpdesk ticket
  2. Fill in "Technical Details" tab (error logs, steps to reproduce)
  3. Click "Analyze with Claude AI" button
  4. View results in "AI Analysis & Code" tab
  5. Optionally open created pull request

Automatic Analysis

Enable "Enable Auto-Analysis" on the customer to automatically analyze tickets on creation.

⚠️ Important: Auto-create PR is disabled by default. Enable with caution as it creates pull requests automatically without review.

Cost Optimization

This module uses prompt caching to significantly reduce API costs:

  • Universal Odoo best practices are cached across all requests
  • Client-specific context (code, config) is cached per client
  • Cache lasts 5 minutes, reducing costs by up to 90%
  • Only fresh ticket data is sent with each request

Estimated costs: First analysis ~$0.10, subsequent analyses ~$0.01-0.02 (with cache hits)

Security

  • GitHub tokens are only visible to system administrators
  • Claude API key stored in system parameters (admin access only)
  • All API calls logged for audit purposes
  • Sensitive data never included in AI prompts
